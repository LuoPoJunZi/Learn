3. 零 JS 互斥手风琴（<details name="faq-group">）

下方三个折叠面板共享相同的 name="faq-group"。在现代浏览器中展开一项时，其余已展开项会自动收起；旧浏览器则平稳退化为普通独立折叠面板。

为什么不再需要手写 30 行 JS 控制手风琴互斥？

HTML 标准为 <details> 引入了类似单选框的 name 分组属性。同组内任意一项打开时，浏览器原生关闭同组其他项，并自动维护键盘焦点与辅助技术状态。

为什么 oklch() 比传统 hsl() 更适合做设计系统？

在 hsl() 中，相同亮度的黄色与蓝色看起来明暗差异极大，极易导致白字对比度不达标；oklch() 按人眼感知亮度 L 设计，切换色相时整体明度更稳定。

不支持新色彩函数的旧浏览器会白屏或失效吗？

不会。我们在 style.css 中先声明了安全的 sRGB 十六进制默认色，再在 @supports 块中覆盖为 oklch() 和 color-mix()，确保旧环境依然可读。
