1. Set 集合方法 ES2024

集合终于拥有了数学集合运算：union（并集）、intersection（交集）、difference（差集）、symmetricDifference（对称差集）。

⚠ 你的浏览器不支持 Set 集合方法，请使用 Chrome 122+ / Firefox 127+ / Safari 17.4+。

2. Promise.withResolvers() ES2024

过去创建可外部控制的 Promise 需要"Deferred"模式（在构造函数外保存 resolve/reject 引用）。新 API 一行搞定。

⚠ 你的浏览器不支持 Promise.withResolvers，请使用 Chrome 119+ / Firefox 121+。
← 先创建一个 Promise，再用按钮控制它的结果 // 旧写法： let resolve, reject; const p = new Promise((res, rej) => { resolve = res; reject = rej; }); // 新写法： const { promise, resolve, reject } = Promise.withResolvers();

3. Iterator Helpers（迭代器辅助方法）ES2025

迭代器终于拥有了 .map()、.filter()、.take() 等方法——惰性求值，不会一次性生成整个数组。

⚠ 你的浏览器不支持 Iterator Helpers，请使用 Chrome 122+ / Firefox 131+。

← 惰性生成斐波那契数列

4. Object.groupBy() ES2024

按指定条件将数组元素分组，返回一个无原型对象。告别手写 reduce 分组逻辑。

⚠ 你的浏览器不支持 Object.groupBy，请使用 Chrome 117+ / Firefox 119+。
