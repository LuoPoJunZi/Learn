WebGPU 通用计算管线 (Compute Pipeline)

与传统的 WebGL 依赖栅格化渲染循环不同，WebGPU 原生支持纯数学**计算管线**，硬件映射至 DirectX 12、Metal 与 Vulkan 底层，无需通过 Canvas 即可让 GPU 参与并行阵列计算：

1. Adapter 请求物理显卡实例
2. Device 建立逻辑设备会话
3. Buffers 显存分配数据缓冲区
4. WGSL 编译着色语言程序
5. Dispatch 多线程工作组并行派发

实战演练：GPU 向量并行相加

我们将两组长度为 4 的一维浮点数组上传至 GPU 显存，执行 WGSL 计算着色器完成并行相加，再将显存计算结果映射回 CPU 内存：

// WGSL (WebGPU Shading Language) 极简计算着色器
@group(0) @binding(0) var<storage, read> inputA: array<f32>;
@group(0) @binding(1) var<storage, read> inputB: array<f32>;
@group(0) @binding(2) var<storage, read_write> outputResult: array<f32>;

@compute @workgroup_size(64)
fn main(@builtin(global_invocation_id) global_id: vec3<u32>) {
    let index = global_id.x;
    if (index < arrayLength(&inputA)) {
        outputResult[index] = inputA[index] + inputB[index];
    }
}
