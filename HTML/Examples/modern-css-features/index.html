1. 原生 CSS 嵌套 (Native Nesting)

Baseline 2023+

在以往，前端工程必须引入 Sass、Less 或 PostCSS 才能书写 & 嵌套。现代浏览器原生支持在选择器内部嵌套子选择器与媒体查询，零编译依赖：

.feature-card {
  padding: 1.5rem;
  & .card-header { display: flex; }
  @media (max-width: 600px) { padding: 1rem; }
}

本页面的样式正是使用纯原生嵌套书写，无需任何前端打包构建工具即可直接在浏览器解析渲染。
