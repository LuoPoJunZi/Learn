2. 不可变性与月份编号（不再从 0 开始）

遗留 Date 调用 setDate() 会原地修改对象，且月份从 0（一月）到 11（十二月）；Temporal.PlainDate 始终返回新对象且月份从 1 到 12。


    


    

      
3. 失败路径：非法日期不再悄悄“进位”

      
传入 2026-02-30 时，旧 new Date(2026, 1, 30) 会静默变成 3 月 2 日；而 Temporal.PlainDate.from(..., { overflow: "reject" }) 会明确抛出 RangeError。
