02 / Native primitives

三项浏览器原语

A

Invoker Commands

按钮直接声明目标和动作，浏览器负责键盘激活与对话框调用。

command="show-modal"

B

Anchor Positioning

浮层跟随触发按钮定位，不再手工读取坐标并监听窗口变化。

position-area: block-end

C

Scroll-driven Animations

页面顶部进度条和本区块入场由滚动时间线驱动，不监听 scroll 事件。

animation-timeline: view()
