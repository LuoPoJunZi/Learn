## 检查器的明确限制

- Markdown 检查验证本地目标路径与代码块，不是完整 CommonMark 解析器，不保证标题锚点和所有引用式链接都正确。
- HTML 检查不完整解析 CSS `url()`、`srcset`、动态路径、远程资源或站点根路径。
- JavaScript 检查不执行 DOM、内联事件属性、远程模块或浏览器 API；独立 `.js/.cjs` 按 CommonJS 解析、`.mjs` 与 `type="module"` 按模块解析，新增 ES module `.js` 项目需要适配其模块配置。
- 基础风险规则是启发式检查，不替代依赖漏洞扫描、完整安全审计或科学算法验证。
