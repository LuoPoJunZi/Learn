# 保形预测：给回归结果配一个区间

## 适合人群与学习目标

适合已经理解“训练数据 -> 拟合模型 -> 预测”的读者。推荐先运行 [线性回归](examples/linear_regression_gradient_descent.py)，再阅读 [过拟合与正则化](examples/overfitting_regularization_demo.py)，最后进入本页。

学习目标：区分点预测和预测区间，理解独立校准集的用途，正确选择有限样本分位数，并认识覆盖保证的适用条件。

本地入口：[split_conformal_regression.py](examples/split_conformal_regression.py)。只需要 Python 3.10+ 标准库，无网络和文件写入。

## 核心概念

### 一个数值没有表达全部误差

假设模型对某个输入预测 `3.05`，但测量值还受随机噪声影响。区间如 `[2.15, 3.95]` 表示哪些结果仍与校准数据中的预测误差相容。它是针对新观测值的预测区间，不是回归斜率的置信区间。

Split Conformal Prediction（分割保形预测）在已有预测器外面增加校准步骤。它不要求预测器必须是神经网络：本例使用最小二乘线性模型，把重点放在区间构造。

### 三份数据各做一件事

| 数据 | 本例数量 | 用途 |
| :--- | :--- | :--- |
| 训练集 | 200 | 拟合斜率和截距 |
| 校准集 | 120 | 估计绝对预测误差的阈值 |
| 评估集 | 1000 | 观察新数据的覆盖比例 |

校准之后不能再用校准集调整模型权重。若确实要调模型，应预留验证集，并在模型确定之后使用独立校准集。评估集同样不能参与区间选择。

## 从残差到区间

对于每个校准样本，计算：

```text
score_i = abs(true_y_i - model_prediction_i)
```

设允许的未覆盖概率为 `alpha`，例如 `0.1` 对应目标覆盖率 `90%`。有 `n` 个校准得分时，使用一开始计数的排序位置：

```text
k = ceil((n + 1) * (1 - alpha))
radius = sorted_scores[k - 1]
interval(x) = [prediction(x) - radius, prediction(x) + radius]
```

`n+1` 是有限样本修正，不能随手改成普通插值分位数。若 `k>n`，本例返回正无穷，这对应在得分列表中补一个无穷大值的保守约定。不要把排序位置强行截断为 `n` 后还宣称相同保证。

例如只有 3 个校准样本且 `alpha=0.1`，`k=4`，需要无限区间。它提醒你：极小的校准集不足以给出很高覆盖目标下的有限区间。

## 如何运行与阅读结果

下面的命令会生成三份独立合成数据，训练模型，然后比较 80%、90%、95% 三个目标：

```powershell
python "Python\Neural Network\examples\split_conformal_regression.py"
```

固定随机种子后，训练模型约为 `y=2.0692*x+0.9843`。当前 Python 运行结果为：

| 目标覆盖 | 区间半径 | 评估集覆盖 | 噪声增大后的覆盖 |
| :--- | :--- | :--- | :--- |
| 80% | 0.7543 | 76.4% | 31.4% |
| 90% | 0.8995 | 85.7% | 37.5% |
| 95% | 1.1720 | 95.0% | 48.3% |

这些是一次运行的实测比例，不是必须达到的测试阈值。90% 这一行低于目标并不自动意味着算法写错：经典保证是对校准样本与新样本的随机性取平均后的边际覆盖，不保证每个固定校准集、每次有限评估都至少达到目标。

程序另外生成噪声标准差从 0.6 增大到 1.8 的评估数据。覆盖显著下降，是因为这批数据与校准数据不再满足相同的数据分布条件。

推荐阅读顺序：`main()` 的数据划分 -> `fit_linear_model()` -> `calibrate()` -> `conformal_radius()` -> `coverage()`。最后的 `assert` 检查排序位置和无限区间边界，而非强行要求某次实测覆盖达标。

## 典型场景与使用边界

- 场景：给回归模型、神经网络回归器或工程预测结果增加误差区间。
- 基本条件：模型已固定，校准得分与新样本得分可交换；独立同分布采样是常见的充分条件。
- 保证是总体边际的，不是针对每个具体输入、类别或人群的条件覆盖保证。
- 时间序列、空间关联数据和分布漂移需要专门设计。不能把本例直接套进现有时间序列案例并沿用同样保证。
- 本例使用相同半径的对称区间。若不同输入区域的噪声大小不同，需要考虑归一化得分或其他方法。
- 半径变大通常提高覆盖，同时降低结果的精细程度；区间越宽不是模型越好。

## 常见误区

1. 用训练误差校准。参考解释：模型已经看过这些标签，误差容易偏小。
2. 根据评估集反复挑选 `alpha`。参考解释：评估变成调参，无法客观验证后续效果。
3. 把区间说成“这个具体样本有 90% 概率在这里”。参考解释：经典边际保证不能直接支持这个逐输入的解释。
